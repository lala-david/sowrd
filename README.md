# 동행 — The Gospel Road

> 신약 4복음서 · 예수님의 생애를 기반으로 한 **모바일 내러티브 어드벤처 RPG**
> 사건 하나하나가 서로 다른 미니게임(퍼즐·물류·리듬·균형·추리)이 되고,
> 깰 때마다 **사람**이 동료로 합류하는 따뜻한 여정.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입체크 + 프로덕션 빌드 (PWA 포함)
```

모바일 우선(세로 화면·한 손 플레이). 데스크톱에서는 폰 프레임으로 중앙 표시됩니다.

## 현재 상태 — 수직 슬라이스 v0.1

플레이 가능: **8장 "내게로 오라" (물 위를 걷다)** — 균형/집중 미니게임
→ 클리어 시 베드로 합류 → 사람 스크랩북(컬렉션)

- 타이틀 → 여정 맵(12장) → 미니게임 → 보상 → 컬렉션 루프 동작
- 세이브 자동(localStorage), 실패해도 진행 무손실
- 접근성: 잔잔한 물결(관대) 모드, reduced-motion 존중

## 원칙 요약

1. **당신은 예수님이 아니다 — 동행자다.** 예수님은 조작하지 않는 NPC, 빛과 사람들의 반응으로 연출.
2. **교훈은 설교가 아니라 기계장치(mechanic)가 짊어진다.**
3. **매 장이 다른 동사** — 다양성이 지루함을 이긴다.
4. **사람을 모으는 따뜻함** — 확률형 뽑기·FOMO·페이투윈 없음.
5. **신학 기준: 대한예수교장로회 통합측(예장통합) 정통 노선.** 이단 교리 배제, 4정경 복음서 본문에 충실.
