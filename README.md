# PROJECT THE WAY

> **Run the Way. Walk with the Gospel.**
> 달리며 따라가는 예수님의 길

내가 달린 거리만큼 예수님의 사역 여정이 이어지고, 누군가를 위한 기도가 공동체 안에 쌓이는 **글로벌 기독교 GPS 러닝 앱**.

*(프로젝트 가칭 — 상표권·앱스토어 중복 확인 후 최종 브랜드명 확정)*

---

## 이게 뭔가요

사용자가 실제로 달리거나 걸은 거리를 GPS로 기록하면서, 사복음서에 나타난 예수님의 공생애를 시간순으로 따라갑니다. 혼자 진행할 수도 있고, 친구·소그룹·교회와 거리를 모아 공동의 복음서 여정을 완성할 수도 있습니다.

러닝 전에 중보기도 대상을 정하고, 달리는 중에는 거리에 따라 짧은 기도 주제와 성경 사건이 제공됩니다.

예배·성경 읽기·교회 공동체를 **대체하지 않습니다.** 신앙생활을 돕는 보조 도구입니다.

## 일반 러닝 앱과 무엇이 다른가

일반 러닝 앱이 거리·페이스·칼로리·기록 경쟁에 집중한다면, 여기에는 세 가지가 더 있습니다.

1. **복음서 기반의 진행형 여정** — 사용자의 이동이 이야기의 진행 조건이 됩니다
2. **개인 및 공동체 중보기도**
3. **예수님의 삶과 오늘의 실천 연결**

## 지켜야 할 선

이 프로젝트에서 **하지 않는 것**들입니다. 기획·개발·콘텐츠 모든 단계에서 지켜집니다.

- 운동량을 구원·축복·믿음의 정도와 연결하지 않습니다
- "믿음 점수", "기도력", "구원 레벨" 같은 수치를 만들지 않습니다
- 성경에 없는 예수님의 말씀을 창작하지 않습니다
- 헌금·결제로 영적 보상이 늘어나는 구조를 만들지 않습니다
- 십자가 사건을 "보스전"이나 "미션 성공"으로 다루지 않습니다

> 우리는 달린 거리로 믿음을 증명하지 않습니다.
> 다만 예수님께서 걸으신 길을 기억하며, 오늘 우리의 자리에서 그 길을 따라갑니다.

## 신학 기준

- **국내 콘텐츠** — 대한예수교장로회 통합(예장통합) 헌법·신앙고백 기준으로 검수
- **글로벌** — 사도신경·니케아신경에 부합하는 정통 기독교 공통 언어로 표현
- **원칙** — 특정 목회자 개인의 해석보다 성경 본문 우선

모든 주요 콘텐츠는 실제 목회자·신학자의 검토 기록을 남깁니다.
각 에피소드 상태: `작성 중 → 성경 본문 검토 → 신학 검토 → 번역 검토 → 현지 검토 → 게시 승인`
