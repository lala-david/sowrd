## ① 목표와 범위

### 목표
1. **"솔로 제작인데 프리미엄으로 보인다"** — 플랫 벡터 SVG 화풍을 단 하나의 스타일 앵커로 고정하고, 모든 에셋이 같은 규칙(팔레트·선·비례·광원·대비 플로어)에서 파생되게 한다. 일관성이 곧 품질이다 (GDD §9).
2. **한 번 그려 여러 번 쓴다** — 캐릭터 = 베이스 1장 + 표정/포즈 레이어 교체. 배경 = 세로 규격 패럴럭스 레이어(권장 3, 상한 5 — 이 수치가 유일 정의이며 ③·⑪은 이를 참조한다). 신규 에피소드의 아트 비용을 한계비용 수준으로.
3. **소리가 감정을 들고, 보상을 만든다** — Howler 기반 2+2 채널 + 파라메트릭 루프(집중 미터→볼륨/피치 매핑). 카드 획득·세트 완성·관계 해금 등 **보상 순간에 오디오 예산을 최우선 배정**한다(수집 게임의 월급날). 무음 플레이도 완전 지원.
4. **엔진과 에셋의 분리** — 에셋은 명명 규칙 + 매니페스트(JSON+Zod)로 관리, 노드 스크립트(`assets:check`)가 참조 무결성·팔레트·용량·라우드니스를 CI에서 검증. 리듬 장(2·10장)의 비트 동기 인터페이스를 지금 예약해 "새 에피소드 = 엔진 수정 0"을 v1까지 보존한다.
5. **신학 가드는 코드다** — 예수님 데이터 격리·감수 게이트·신학 용어 네이밍 검사를 Zod refine + CI 하드 에러로 강제(③-G). 문서 선언만으로는 게이트가 아니다.

### 비범위 (이 플랜에서 다루지 않음)
- 미니게임 각각의 게임플레이 설계(별도 플랜 — 단 오디오 파라미터 매핑 계약은 ⑥에 정의), ink 대사 파이프라인, 세이브 시스템 본체(persist 계약만 참조: 스토리지 키 `donghaeng-save-v1`, version 미지정=0 기준 마이그레이션 — 공통 지침 8).
- 3D·실사·풀 픽셀아트(GDD §9 기각), Pixi 파티클(v1 이후 — 인터페이스 자리만 예약).
- 성우 보이스, 절차적 음악 생성.
- 캡패시터 네이티브 오디오 최적화 — PWA 기준 먼저 완성(단 v1 회귀 테스트 항목은 유지).

## ② 플레이어 경험 시나리오

**S1 — 첫 진입(타이틀).** 심야 인디고 하늘. 소리가 나기 전 3초를 비주얼 훅이 책임진다: 등불 앰버 별의 맥동(주기 1.6s, 스케일 ±6%), 수면 하이라이트의 느린 흐름, 로고 세리프의 순차 등장(0.8s). 첫 터치("여정 시작") 순간 `bgm_title`이 1.5초 페이드인 — 자동재생 정책의 무음 구간을 "정적 → 첫 음"의 연출로 전환한다. reduced-motion 시 맥동은 투명도 변화(모션 없는 글로우)로 대체.

**S2 — 여정 맵.** 세로 배경 3레이어 패럴럭스(하늘/능선/길)가 미세하게 흐른다. 노드 탭 SFX `sfx_tap`(레퍼런스: ⑦-D 표의 지정 트랙 — 형용사 명세 금지). BGM은 `bgm_journey`(인트로부+루프부 분리)이며, **동료 수에 따라 악기 스템이 해금**되어 수집이 진행될수록 맵 음악이 풍성해진다(⑥-C).

**S3 — 미니게임(물 위 걷기).** BGM `bgm_night_sea`(저역 위주). `sfx_focus_loop`의 볼륨·피치가 집중 미터에 실시간 매핑(⑥ `setLoopParam`) — 소리를 켠 플레이가 실제로 더 잘 들리게. 침몰 위기의 해소는 플레이어 조작이 아니라 **예수님의 붙잡으심 연출 비트**이며(공통 지침 2, 마 14:31 "즉시 손을 내밀어"), 이 비트에 `sfx_hand_reach`가 귀속된다. 클리어 시 `sfx_clear_warm`(성취 신호 — '은혜' 명칭 사용 금지, MF-4). 첫 클리어에 한해 BGM 정지 후 800ms의 정적 → 리워드 BGM. **정적도 오디오 연출이지만 반복 시 마모된다**: 2회차 300ms, 3회차부터 생략(⑤). 정적 중 유저 입력은 즉시 인터럽트. 정적의 시각 등가물(화면 1단계 암전→밝아짐, 램프 500ms)을 항상 동기화 — 무음 사용자에게도 같은 호흡이 존재한다.

**S4 — 동료 카드 획득(리빌 세리머니).** 단발 SFX 하나가 아니라 ⑥-B의 5단계 시퀀스(빌드업→플립→표정 전환→성구 등장→진행 틱)로 연출한다. 감정 클라이맥스는 **인물 플립+표정 전환**이고 성구는 여운(코다)이다. 한 에피소드에서 복수 카드를 얻는 4장(베드로·안드레·마태·요한)·9장(등장인물별 카드)은 ⑥-B **다중 획득 배치 규칙**(2장째부터 축약, 총 5초 상한, 스팅어 일괄 1회)을 따른다. 획득이 세트 완성이면 `stinger_set_complete`. 스킵 탭 시 즉시 최종 상태 + 오디오 100ms 페이드. aria-live(polite)로 "『베드로』 카드 획득" 알림.

**S5 — 예수님 등장 장면.** 동일 화풍의 실제 캐릭터. 등불 앰버 림라이트 + 화면 휘도 +1단계(델타 ≤15%, 램프 ≥500ms — 광과민 안전 수치, reduced-motion 시 휘도 변화 없이 림라이트만). 전용 모티프 `bgm_presence`(레퍼런스·회피 기준은 ⑦-D, 타종교 명상음 연상 배제 — T9). 희화화 SFX 절대 금지.

**S6 — 무음/접근성 사용자.** 모든 오디오 피드백은 시각으로 중복 전달(정적 포함 — S3). 전 화면 상단에 즉시 음소거 토글(≥44px), 설정 시트에 BGM/SFX 단계형 볼륨(끔/약/중/강)과 인앱 "모션 줄이기" 토글 — OS 설정을 모르는 8세·70대를 위한 인앱 1급 제어. 모두 persist. 집중 유지형 미니게임 중 시각 토스트 출력 금지(공통 지침 6).

**S7 — 재방문(하이드레이션).** persist 복원으로 곧장 map/collection에 떨어져도 `useAudio`가 "하이드레이션 완료 시 현재 화면 기준 BGM 결정" 규칙으로 올바른 트랙을 페이드인(언락 전이면 큐잉, ⑥-A). 재진입 3초의 첫인상을 무음이나 오트랙으로 깎지 않는다(ENGAGEMENT §8).

### ③-G 신학 가드 — 스키마·CI 코드 스케치 (공통 지침 1·3, MF-4)

문서 선언이 아니라 기계 강제다. 아래 refine이 실패하면 `assets:check`가 비정상 종료하고 CI가 프로덕션 빌드를 막는다.

```ts
export const JESUS_ID = 'jesus' as const

/** G1 — 예수님 데이터 격리: 수집·유대·선물·아트 참조 어디서든 jesus id 차단 */
export const CollectibleArtRefSchema = z.string().refine(
  (id) => id !== JESUS_ID,
  { message: 'THEO-GUARD G1: jesus는 수집 카드/유대/선물 아트 참조 대상이 될 수 없다' },
)
// collection·progression 플랜의 CompanionSchema도 동일 refine을 공유(공용 가드 모듈로 export)

/** G2 — 감수 게이트: reviewed를 콘텐츠 해시에 묶어 수정 시 자동 해제 */
export const ReviewGateSchema = z.object({
  reviewed: z.boolean(),
  reviewHash: z.string(),              // 에셋 파일 + 가이드 문서의 sha256
  reviewers: z.array(z.string()).min(2), // 신학 전공 목회자 2인 이상 (⑩-A)
  decisionLog: z.string(),             // docs/review/decisions/YYYY-MM-DD-{id}.md 경로
})
// CI 규칙: id==='jesus' 또는 tier==='extra'(적대자 포함) 에셋에서
//   reviewGate 부재 → 하드 에러
//   reviewed===false 또는 reviewHash !== 현재 파일 해시 → 프로덕션 빌드 실패(dev는 워터마크 표시)

/** G3 — 신학 용어 오디오 네이밍 가드 (MF-4) */
const THEO_TERMS = ['grace', 'holy', 'divine', 'miracle', 'bless', 'presence', 'spirit']
const THEO_AUDIO_WHITELIST = ['bgm_presence'] // T3 감수 승인 id만 등재(승인 로그 경로 병기)
export const AudioManifestSchema = z.array(AudioAssetSchema).superRefine((list, ctx) => {
  for (const a of list) {
    const hit = THEO_TERMS.find((t) => a.id.includes(t))
    if (hit && !THEO_AUDIO_WHITELIST.includes(a.id)) {
      ctx.addIssue({ code: 'custom',
        message: `THEO-GUARD G3: '${a.id}' — 신학 용어 '${hit}' 차용은 T3 감수 승인(화이트리스트) 필요` })
    }
  }
})

/** G4 — 예수님 표정 전 종 필수 (스키마 레벨 + U2 테스트 이중화) */
export const CharacterArtListSchema = z.array(CharacterArtSchema).superRefine((list, ctx) => {
  const jesus = list.find((c) => c.id === JESUS_ID)
  if (!jesus) return
  for (const e of ExpressionSchema.options) {
    if (!jesus.expressions[e]) ctx.addIssue({ code: 'custom',
      message: `THEO-GUARD G4: jesus 표정 '${e}' 누락 — lead 티어 전 표정 필수` })
  }
})
```

설계 결정:
- **에셋 경로는 매니페스트에만 존재.** 검증 메커니즘은 "빌드 시점 import.meta.glob"이 아니라(public/ 파일은 glob 대상이 아니고 Zod는 런타임 검증 — 엔지 지적 수용) **node 스크립트 `assets:check`가 fs로 매니페스트 경로 실존을 대조**하는 방식으로 일원화한다. U1/U2와 동일 코드 경로.
- **표정 7종 + 티어제** — surprise를 지금 확정(이적 목격 리액션), lead/support/extra 티어로 "전 로스터 동시 적용" 비용 폭발을 구조적으로 차단(비신자 low·게임D low 수용).
- **오디오 포맷 webm(opus 48kbps) 우선 + mp3(96kbps) 폴백** — 기기당 실제 다운로드는 1포맷(⑪ R4 산수 표).

engine.ts 핵심 명세 (MF-16·17):
- **React를 모른다.** Howl 생명주기·크로스페이드·언락·정적 큐를 전담하는 싱글턴.
- **채널 분리(v3 개정 — html5/loopStartMs 모순 해소, V3-2)**:
  - SFX/스팅어/모티프 = WebAudio 스프라이트(저지연) — 불변.
  - BGM/스템 = **인트로/루프 하이브리드**. Howler `html5: true`는 타이머 기반 시킹이라 샘플 정밀 루프 포인트가 불가능해 루프마다 수십~수백 ms 갭·드리프트가 생긴다 — 심리스 커스텀 루프는 WebAudio 버퍼에서만 성립한다. 따라서: **인트로 파트 = html5 스트리밍 1회 재생**(`introSrc`), **루프 본체 = WebAudio 버퍼**(모노 다운믹스, 루프 길이 상한 40초, `loop: true` 샘플 정밀 반복).
  - **메모리 산수(MF-16 회피 근거 유지 검증)**: 루프 본체 PCM = 40s × 48kHz × 4B × 모노 1ch ≈ **7.7MB/트랙**, 크로스페이드 동시 2트랙 ≤ **15.4MB** — 90초 스테레오 풀 디코드(≈30MB×2=60MB) 대비 1/4. 2GB 기기 예산 내. 스템은 맵 한정 최대 2(모노 30초 이하 ≈ +11.5MB 상한).
  - **체인 규칙**: 인트로→루프 전환점은 샘플 정밀이 필요 없다 — 인트로 종료 300ms 전에 루프 본체를 크로스페이드 인입(의도된 전환으로 설계). 루프 내부 반복만 샘플 정밀이면 된다.
  - **확정 게이트**: ⑧ M0 스파이크(R9 병합)에서 실기기 2종(저가 안드로이드·iOS Safari) html5 루프 갭 실측. 갭 ≤50ms·드리프트 무시 가능 판명 시 단일 html5+`loopStartMs`로 다운스코프 가능(호출부 API 불변). **어느 결론이든 트랙 납품 포맷은 인트로/루프 2파일 분리** — 정책이 뒤집혀도 오디오 재작업 0.
- **BGM lazy 정책**: 화면 진입 시 Howl 생성, 크로스페이드 완료 후 직전 트랙 `unload()`. 동시 유지 상한 2트랙(크로스페이드 중) + 스템 최대 2(맵 한정).
- **언락 정책(채널별, 모순 해소)**: 언락 전 BGM 요청 = 최신 1건만 보관 후 재생, 언락 전 SFX = 전부 폐기(늦게 터지는 SFX는 무의미).
- `CharacterSprite`는 `<img>` 2장 겹침 기본, 표정 크로스페이드 120ms. 컨테이너에 단일 alt(인물명), 표정 레이어는 `aria-hidden`(⑦-B).

## ⑤ 핵심 플로우 (상태 전이)

### BGM 상태 기계 (engine.ts 내부)
```
        play(id)                  play(id2)
 idle ──────────► playing(id) ──────────────► crossfading(id→id2)
   ▲                  │  ▲                          │ 완료 시 이전 Howl unload
   │        stop()    │  └──── 2s 완료 ◄────────────┘
   └──────────────────┘
 silence(ms, {interruptible:true}) — 페이드아웃 후 의도적 정적.
   · 유저 입력(pointerdown) 발생 → 정적 즉시 종료 + 큐된 play 즉시 실행 (MF-8)
   · 회차 축약: 동일 연출 지점 1회차 800ms → 2회차 300ms → 3회차+ 0ms(생략)
     (회차 카운트는 store의 에피소드 클리어 수를 useAudio가 조회)
   · 시각 등가물(암전→밝아짐 램프)과 항상 동기 발화 (⑥-A)
```
- 크로스페이드 기본 2000ms, 동일 id 재요청 멱등.
- `visibilitychange` hidden → 페이드아웃 후 pause. 복귀 시 **`Howler.ctx.state === 'suspended'`면 `ctx.resume()` 선행 후** resume(iOS standalone PWA 케이스, 엔지 low 수용).

### 모바일 오디오 언락 플로우
```
 locked ──(첫 pointerdown 1회 리스너)──► unlocked
   │  BGM: 최신 1건만 보관             │ BGM 1건 재생
   │  SFX: 즉시 폐기                   │ (플러시할 SFX 없음)
   └── Howler autoUnlock 병행, 실패해도 게임 진행 무영향 ─┘
```

### 표정 전환 / 패럴럭스
```
 expr A ──setExpression(B)──► 120ms 크로스페이드 ──► B
 B 미존재 → neutral 폴백 + dev 경고 (프로덕션 조용히 폴백)

 패럴럭스: 마운트 → 레이어 디코드 → depth별 transform
 reduceMotion(인앱 토글 OR prefers-reduced-motion) → 전 연출 정적 폴백
   적용 범위 = 패럴럭스·카드 플립·전화면 휘도 변화 포함 "전 연출" (공통 지침 6)
 저사양 대응: 자동 감지 제거(MVP) → 설정 "연출 줄이기" 수동 토글. 자동 감지는 v1 과제.
```

### 오디오 명령 API (다른 시스템이 호출하는 유일한 표면)
```ts

audio.playBgm(id, opts?: { fadeMs?: number; stems?: string[] })

audio.silence(ms, opts?: { interruptible?: boolean })    // 기본 true

audio.setLoopParam(h: LoopHandle, p: { volume?: number; rate?: number })
  // 집중 미터→오디오 매핑: volume 0.4~1.0, rate 0.95~1.08 (물 위 걷기 계약, MF 게임D)
audio.setLevels(s: AVSettings)                           // store 구독 자동 반영
// ── 리듬 장 예약 인터페이스 (MF-10, 구현은 스파이크 후 확정) ──
audio.getPlaybackTime(channel?: 'bgm'): number           // AudioContext 클록 기준 초
audio.onBeat(bpm: number, offsetMs: number, cb: (beatIndex: number) => void): () => void
  // Howler 정밀도 부족 판명 시 Web Audio 직결 경로로 내부 교체 — 호출부 시그니처 불변(R9)
```

### ⑥-A 화면 ↔ 오디오 바인딩 계약 (useAudio 소유)
| 트리거(store 상태) | 오디오 반응 | 시각 등가물(무음 사용자) |
|---|---|---|
| `screen === 'title'` | `playBgm('bgm_title')` (언락 전이면 최신 1건 큐) | 별 맥동 비주얼 훅(S1) |
| `screen === 'map'` | `playBgm('bgm_journey', { stems: 해금분 })` | 스템 해금 시 맵 등불 1개 점등 |
| `screen === 'collection'` | `playBgm('bgm_journey_calm')`(journey 변주) · 카드 상세 진입 시 `motif_{id}`(1~2초) 오버레이 | 카드 상세 진입 글로우 |
| `enterEpisode(id)` | `EpisodeAssets[id].bgm` 크로스페이드 | 배경 전환 |
| `completeEpisode(...)` | `silence(회차별 800/300/0)` → 리워드 진입, 리빌 세리머니(⑥-B)가 이후 오디오 소유 | 암전→밝아짐 램프 500ms |
| **하이드레이션 완료**(persist 복원) | 현재 `screen` 기준 트랙을 즉시 결정·페이드인(언락 전이면 큐) — 재진입 3초 무음 금지 | 마지막 장면 즉시 복원 |
| `gentleMode` 변경 | no-op (계약상 명시) | — |
| 집중 유지형 미니게임 중 | — | **시각 토스트 출력 금지**(공통 지침 6) — 판정 정보는 미터·형태로만 |

- **셀렉터 계약:** `useAudio`는 `screen`·`currentEpisode`·하이드레이션 플래그만 구독. 미니게임 내부 SFX는 게임 컴포넌트가 `playSfx`/`setLoopParam` 직접 호출 — store를 오디오 이벤트 버스로 쓰지 않는다.
- **아트 계약:** `companion.id → CharacterArt.id` 동일 키. 매니페스트 부재 시 텍스트 카드 폴백은 **dev 빌드 전용**(⑪ R13 릴리스 게이트) — 프로덕션 빌드에서 수집 대상 인물의 아트 부재는 `assets:check` 하드 에러.
- **미래 예약:** Pixi 이펙트·리듬 판정 스케줄러 모두 이 API 뒤에 숨긴다(호출부 불변).

### ⑥-B 리빌 세리머니 시퀀스 (카드 획득 — 보상의 월급날, MF-6)
| t(ms) | 연출 | 오디오 | 접근성 |
|---|---|---|---|
| 0~500 | 빌드업: 배경 1단계 암전, 카드 후광 수렴 | `sfx_reveal_rise` | reduced-motion: 정적 글로우 |
| 500~900 | 카드 플립 | `sfx_card_flip` | 플립 대신 크로스페이드 |
| 900~1020 | 표정 neutral→joy 120ms | — | — |
| 1020~1600 | 인물명·성구(세리프, `--ink-on-light` on `--parchment`) 순차 페이드 | `sfx_verse_ink` | aria-live polite "『베드로』 카드 획득" |
| 1600~2000 | 유대/컬렉션 진행 틱, 관계 심화 해금 시 | `sfx_meter_tick` · `sfx_relation_up` | 진행 바 수치 병기 |
| 조건부 | 세트 완성(예: 4장 제자 세트) | `stinger_set_complete` | aria-live "제자 세트 완성" |
- 스킵: 탭 1회 → 현재 카드 즉시 최종 상태, 오디오 100ms 페이드아웃. 스킵과 싸우지 않는다.
- **클라이맥스 정의(V3-6)**: 시퀀스의 감정 정점은 플립+표정 전환(= 인물 획득 그 자체)이고, 성구는 여운(코다)이다. "성구 등장이 보상"이라는 가정은 ⑨-C P10에서 비신자 서브그룹으로 검증하며, 실패 시 성구 전문은 카드 상세(선택 열람)로 이관하고 리빌은 인물 연출로 종결한다 — 시퀀스 구조상 성구 단계만 떼어내면 되므로 폴백 비용은 낮다.
- M0 합격 기준에 "카드 획득 순간이 기분 좋다"(⑨-C 리커트 4/5) 포함.

**다중 획득 배치 규칙 (연속 N장 — 4장 제자 부름·9장 비유 카드 다발, V3-1):**
동일 2.0초 시퀀스의 N연속 반복은 월급날을 야근으로 만든다. MVP 시연 장(4장)이 바로 다중 획득 장이므로 아래 규칙이 1회차부터 적용된다.
| 규칙 | 값 |
|---|---|
| 1장째 | 풀 시퀀스 0~1600ms(빌드업+플립+표정+성구) — 단, 진행 틱은 발화하지 않고 유보 |
| 2장째부터 | **빌드업(0~500ms) 생략**, 플립 400→250ms, 표정 전환 120ms 유지, 성구는 1행 요약 330ms(전문은 카드 상세) — **카드당 0.7초** |
| 오디오 변주 | `sfx_card_flip` rate를 장마다 +3%(1.00→1.09) — 같은 소리의 반복이 아니라 상승감으로 |
| 진행 틱·스팅어 | **마지막 장에서만 일괄 발화**: 진행 바 합산 카운트업 600ms + `sfx_meter_tick` 연속, 세트 완성 시 `stinger_set_complete` 1회 |
| 총 연출 상한 | **4장 기준 ≤5.0초** (실산: 1.6 + 0.7×3 + 일괄 틱 0.6 = 4.3초, 버퍼 0.7초). 상한 초과 시 성구 요약부터 자동 압축 — U16이 상한을 테스트로 강제 |
| 스킵 | 탭 1회 = 현재 카드 즉시 완료, 연속 2탭 = 잔여 카드 전부 요약 그리드로 일괄 표시 + 오디오 100ms 페이드 |
| 접근성 | aria-live 알림은 마지막 1회로 병합("카드 4장 획득: 베드로, 안드레, 마태, 요한") — 카드당 낭독 스팸 금지 |
| 회차 변주와의 결합 | 재클리어 시(⑥-C) 빌드업 생략이 이미 적용되므로 중복 감산 없음 — 다중 배치 규칙이 우선 적용된다 |

### ⑦-A 팔레트 통일 규칙 (실제 `global.css` 토큰명이 유일한 진실 — 공통 지침 9)

SVG 내부 fill/stroke가 화이트리스트 밖이면 `assets:check` 실패(U10 — 삭제된 paletteLock의 실제 강제판).
- **신규 토큰 3종 신설**: `--ink-on-light: #332b1c`(양피지 위 다크 텍스트 — 공통 지침 6), `--skin-1: #e8c39a` `--skin-2: #c68b59` `--skin-3: #8a5a3b`(1세기 유대·지중해 고증 피부톤 3단, 전 인물 공용 — 백인화 클리셰 회피, GDD §9).
- 타이포: 감정·성구 = `--serif`(Noto Serif KR), UI = `--sans`(Noto Sans KR). 에셋 내 텍스트 베이킹 금지 — 텍스트는 항상 DOM 렌더.

| 강조·버튼 | `--lamp` / `--ground` | **10.1:1** | 4.5:1 | 통과 |
| 강조 on 패널 | `--lamp` / `--panel` | **8.7:1** | 4.5:1 | 통과 |

- **규칙**: 판정에 관여하는 시각 요소는 인접 배경 대비 ≥3:1, 텍스트 ≥4.5:1. `ambientTint`는 **UI/텍스트 레이어 아래에만** 적용(검증된 텍스트 대비를 장면 톤이 무너뜨리지 않게 계약으로 명시). `assets:check`에 장면 스크린샷 기반 대비 자동 검사 1건(⑨-D).
- **스크린리더 규칙(한 단락)**: 인물 아트 컨테이너 = 단일 alt(인물명), 표정/포즈 레이어 = `aria-hidden`, 카드 획득·에피소드 클리어 = `aria-live="polite"`, 장식 배경 레이어 = `role="presentation"`. U7 스냅샷에 접근성 트리 검증 포함.
- **모션·휘도 안전 수치**: 전화면 휘도 변화 델타 ≤15%, 램프 ≥500ms. reduce-motion 시 휘도 변화 자체를 생략.
- **대안 입력 1급 계약(V3-5, 공통 지침 6)**: 전 화면 키보드 포커스 순회 가능(Tab/방향키·Enter 활성화), 미니게임 핵심 입력(탭·홀드)은 Space/Enter 등가 바인딩 + 단일 스위치 모드(홀드=토글 전환) 제공. 포커스 링 = `--lamp` 2px 아웃라인 — `--ground` 위 실측 **10.1:1**, `--panel` 위 **8.7:1**(비텍스트 플로어 3:1 충족, 위 표와 동일 값). 실기기 체크리스트에 "키보드만으로 물 위 걷기 1판 완주" 1건 포함.
- **텍스트 확대(V3-5)**: 브라우저 200% 확대·OS 폰트 스케일 1.3×에서 레이아웃 파괴·텍스트 잘림 없음 — 텍스트 DOM 렌더 원칙(⑦-A, 에셋 베이킹 금지)과 rem 단위가 전제. 성구 카드 본문 최소 14px, 확대 시 세이프 존 내 리플로우(가로 스크롤 금지). I4 실행 시 200% 확대 조합 1회 검증.

### ⑦-D 오디오 앵커 · 레퍼런스 규정 (MF-23)
- 아트와 동일한 앵커 게이트: **`bgm_night_sea` 1트랙을 오디오 앵커로 제작·승인 후 양산**(M1~M2 게이트). 승인 전 정식 트랙 발주·양산 금지.
- **형용사 명세 금지** — 전 트랙·SFX는 `refTrack` 필수(스키마 강제): 기존 게임/곡의 특정 구간을 지정(예: "sfx_tap — 목질 idiophone, 어택 5ms/디케이 200ms, 레퍼런스: Alto's Odyssey 노드 탭 계열"). 레퍼런스 목록은 audio.ts 매니페스트에 데이터로 존재.
- **회피 기준(T9 감수 체크리스트와 공유)**: 싱잉볼·챈트·무속 타악 연상 음색, 뉴에이지 명상음 클리셰(무한 리버브 패드 단독) 금지. `bgm_presence`는 이 기준으로 청취 감수.
- **라우드니스**: 전 트랙 **-16 LUFS(모바일 표준) ±1**, 트루피크 ≤ -1dBTP, 스팅어 순간 피크도 동일 상한. "경고음은 크기가 아니라 음색으로 구분" 원칙. `assets:check`가 ffmpeg loudnorm 스캔으로 검사(U11).
- **포맷·용량 상한(재산정, MF-7)**: webm(opus 48kbps≈6KB/s) 경로 ≤6MB, mp3(96kbps) 폴백 경로 ≤10MB. 기기당 1포맷만 다운로드. 상세 산수는 ⑪ R4.

### ⑦-E 화풍 앵커 + 캐릭터 매력도 (docs/art/style-anchor.md 성문화, MF-20)
1. **형태**: 단순화된 기하 실루엣 + 라운드. 외곽선은 "없음(면 대비)" vs "딥 인디고 1.5px" 중 **앵커 1장에서 확정** — 단 1.5px 안은 M1에서 실기기 3종(저가 안드로이드 포함) 축소 렌더 비교 통과가 조건(서브픽셀 뭉개짐 검증, 필요시 `vector-effect: non-scaling-stroke` 또는 외곽선 없음으로 확정).
2. **광원**: 등불 앰버 단일 광원(우상단). 그림자는 인디고 2단 멀티플라이 1장.
3. **비례**: 성인 5.5등신, 아동 4등신. 얼굴 단순화(점·선 눈썹, 면 코) — 언캐니 회피. **단, 단순화가 몰개성이 되면 수집 게임은 죽는다.** 아래 매력도 체크리스트가 균형추다.
4. **질감**: 노이즈 오버레이 6% 1종만.
5. **캐릭터 매력도 체크리스트(앵커 승인 조건)**:
   - 실루엣 식별성: 채색 없는 실루엣만으로 5인 중 4인이 인물 구별(블라인드 테스트).
   - 시그니처 배색: 인물별 토큰 조합 비율이 고유(예: 베드로 `--sea` 60/`--parchment` 30/`--dawn` 10).
   - 시그니처 소품(`accent`): 베드로 그물, 안드레 물고기 두 마리, 마태 동전궤, 요한 두루마리 — 카드·포즈에 항상 동반.
   - 포즈 개성: base 포즈가 인물 성격을 드러냄(정면 차렷 금지).
6. **앵커 제작 순서**: 베드로 1장(스타일 앵커, 매력도 체크리스트 통과) → **T8 1차 이단 도상 스크리닝(팔레트·빛 문양·림라이트 포함)** → 예수님 1장(감수용) → 승인 후 양산.
