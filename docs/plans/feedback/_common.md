# 전 시스템 공통 수정 지침 (1차 검증 교차 결론 — 개정판 필수 반영)

1. **예수님 데이터 격리 (최우선)** — 예수님 id가 bond(관계 수치)·collect(카드 수집)·선물·대화풀 대상이 되는 것을 Zod refine + CI 하드 에러로 기계적으로 차단. 문서 선언만으로는 불충분.
2. **마태복음 14:31 재설계** — 위기(침몰)의 해소는 플레이어 조작이 아니라 예수님의 행동(조작 불능 '붙잡히심' 연출 비트)으로. 게임적 도전은 그 이전 구간까지. "말씀과 붙잡으심은 한 동작"(즉시 손을 내밀어).
3. **감수는 상설 게이트** — reviewed 플래그를 콘텐츠 버전 해시에 묶고 수정 시 자동 해제. 감수 범위 = 노출되는 전 텍스트(잡담·카드 문구·토스트·능력 대사 포함). 감수 주체(통합측 목회자 2인 이상)·반려→재검 절차 명문화. 미승인 시 프로덕션 빌드 실패.
4. **개역개정 저작권** — 대한성서공회 사용 허락 절차를 M1 이전 선행 과제로. 컴파일 단계에 인용문-본문 자동 대조 검증(diff) 추가.
5. **재미의 실체 (게임D·비신자 점수를 끌어올릴 핵심)** —
   - 보상에 신앙 전제 없는 실체 레이어 1차 추가(전용 연출·스토리 비네트·스크랩북 코스메틱·일러스트 해금). 묵상문은 선택 열람.
   - 능력→에피소드 유용성 매트릭스(12장×5동사), "영입 후 최소 2개 장에서 유효" 규칙, 보유/미보유 A/B 수치 검증.
   - 30~90초 마이크로 보상 리듬을 계약(reportMoment)으로 보장. 소진 정책 kind별 분리(once/perSession/onChange).
   - 유대 포인트 경제 산수표(만렙 도달 가능성 산술 증명), 에피소드 동반 유대 가산.
   - 모든 선택은 최소 1회 가시적 콜백. 읽히지 않는 flag CI 경고. outro에 미니게임 결과 변수 재주입.
   - 병렬 해금(9장 비유 3편 등)을 기본 구조로 — 선형 외길 금지.
   - 플레이테스트 지표에 '재미·추천 의향·수집 욕구' 추가, 비신자 게이머 쿼터(최소 2~3인).
6. **접근성 수치 플로어** — 텍스트 4.5:1, 비텍스트 3:1을 스펙 표에 실측치로 병기. 양피지 위 다크 텍스트 토큰(--ink-on-light) 신설. reduced-motion 전역 규칙(전 연출 정적 폴백). 키보드/스위치 대안 입력 1급 계약. 집중 미니게임 중 시각 토스트 금지.
7. **테스트 인프라 선행** — git init + vitest 셋업을 M0 첫 태스크로 명시. 미니게임 틱 로직은 순수 함수 추출 후 시뮬레이션 테스트.
8. **실코드 정합** — persist version 미지정(=0) 기준 마이그레이션, 스토리지 키 'donghaeng-save-v1' 유지, 세이브 쓰기 경로 단일화, 레지스트리 Record<minigameId,·> + episodeId 역조인(1:N), 배경 에셋 세로(portrait) 규격, S1(45초 토스트)↔R2(균형 동사 홀드) 모순 해소.
9. **디자인 토큰 통일** — 실제 global.css 토큰명(--ground/--lamp/--dawn/--parchment) 기준. 신규 토큰은 명명 규칙 따라 추가, hex 하드코딩 금지.
10. **ep12 이원화** — 수난(quiet·절제)과 부활(기쁨의 해방) 두 비트로 분리. 부활의 승리를 침묵시키지 말 것.
