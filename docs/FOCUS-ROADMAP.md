## 🎯 NOW — WIP=1 : "수요 검증 스프린트" (코드 아님)

지금 유일하게 진행하는 큰 일. **새 기능 추가 동결.** 이유: 실 GPS·계정·공동체를 지금 만들면 수백 시간이 들지만, **원하는지조차 모른다.** 싸고 되돌릴 수 있는 검증을 먼저.

**포함:**
1. **문제 인터뷰 10~15건** — 소그룹 러너 + 비교용 일반 러너 ([[VALIDATION]] §1).
2. **경쟁앱 리뷰 코딩** — Strava/NRC 스토어 리뷰에서 pain point 출처화 ([[VALIDATION]] §2).
3. **랜딩 스모크테스트** — 대기자 랜딩 2종(포지셔닝 A/B), 전환율 측정 ([[VALIDATION]] §3).
4. **문서 정합 마무리** — [[DECISIONS]] 후속 편집 4건(MASTERPLAN 강등 배너 등).

**Definition of Done:** [[VALIDATION]] §4 성공 임계값에 대해 통과/실패 **판정이 나옴**(가설이 데이터로 반증 가능해짐).
**기간 목표:** 2~3주.
**여기서 손대지 않는 것:** 실 GPS·계정·공동체·오디오·공유카드·추가 여정 — 전부 Next/Later.

## ▶ NEXT — 검증 통과 시에만 : "비치헤드 파일럿"

[[VALIDATION]] 게이트를 통과하면 착수. **예수 여정 하나**를 실제 소그룹 1~2개(디자인 파트너)에 넣고 **리텐션 실측**.

- **실 GPS 연동** — `useRun.tick`의 시뮬을 geolocation으로 교체(`STATUS §5` "그 지점만 교체"). 출발지 난독화 포함.
- **최소 계정** — 기기 넘어 진도 유지 + 소그룹 초대코드용 신원.
- **공동 목표 1종** — 소그룹 거리 합산 → 공동 자리 해금(`PLANNING §6.2 A`). 하루 기여 상한.
- **온보딩** — 첫 러닝 5분 내 첫 자리 해금 + "품은 사람 1명"(첫 성공 보장).
- **측정:** 가입→첫 러닝 완료율 · 첫 자리 완료율 · **D7/D30 리텐션** · 중보 대상 선택률 (`PLANNING §16` KPI에 임계값 부여 — [[VALIDATION]] §4).

**Definition of Done:** 실 소그룹에서 코어 루프가 돌고 **D7 리텐션 임계값** 판정이 나옴.

## ⏸ LATER — 검증·파일럿 성공 후, 이 순서로 해금

주차된 자산을 순서대로 연다. **지금은 전부 잠금.**

1. **무신론 온램프(0층)** — "품은 사람" 카드 공유로 친구 유입 (`GROWTH.md §4`).
2. **공유카드 실 export** — 6종 중 2종부터(자리 도착 리빌 · 협력 목표). Canvas PNG + 프라이버시 트리밍.
3. **다중 여정 해금** — 아브라함 → 출애굽 → 바울 → 베드로 순차(데이터 이미 존재).
4. **전례력 시즌** — 사순/대림/고난주간(비치헤드가 이미 절기로 유입되므로 우선순위 높은 Later).
5. **성구 오디오 가이드런** — NRC 격파 무기([[DECISIONS]] D4). 여기서 착수.
6. **B2B 교회 라이선스** — 관리자 대시보드·기관 과금 (`PLANNING §14.2`).
7. **글로벌 확장** — 미국·브라질 + 영어·포르투갈어 (`GLOBAL-MARKET §5` Phase 1 확장).
8. **실제 순례길 모드** — 카미노 등 6종 (`MASTERPLAN §1`).
