# THE WAY — 마스터플랜 (2026-07-23)

> 오늘 세션의 대전환: 단일 "예수님 사역 러닝"에서 → **다중 성경 여정(아브라함·출애굽·예수·바울·베드로) + 실제 순례길 + 실거리 러닝 + 게임형 진행 + 신앙 공동체(중보기도)** 플랫폼으로 재설계.
> 원칙: 문서만 쌓지 말고 **돌아가는 것**을 만든다 · 신학은 **장로교 통합(PCK)** 기준 · **런닝 중심**(걷기도 허용하되 러닝 우선) · 스트라바 네온 금지, **따뜻한 순례길** 팔레트 유지.

## 2. 실거리 러닝 백엔드 (연구 완료 — `jesus-journey.json`·별도 BACKEND 문서화 예정)
- **라우팅:** 자가호스팅 **GraphHopper**(`round_trip` 알고리즘 — 목표거리 루프 코스 생성 유일 오픈소스). 대안 Mapbox(관리형), OSRM/Valhalla/BRouter.
- **왕복/루프:** GraphHopper round_trip(seed로 여러 코스 제안) 또는 isochrone+route.
- **고도:** Open-Elevation/OpenTopoData(자가호스팅) 또는 엔진 내장(SRTM).
- **타일:** MapLibre GL JS + **Protomaps(.pmtiles 자가호스팅, 무과금)** 또는 MapTiler(관리형 무료티어).
- **아키텍처:** 클라 geolocation → 라우팅 API → GeoJSON 코스(거리·고도·예상시간) → 실거리 누적을 성경 여정 폴리라인에 매핑 → 자리 해금.
- **프라이버시:** 집 주변 출발 난독화(±100~300m), 프라이버시 존, 원본 GPS 기본 미저장(누적 거리만). 자가호스팅 시 좌표 3자 미전송.

## 3. 경쟁사 격파 — NRC·Strava 뛰어넘기 (연구 완료)
**NRC 강점**(가이드런·따뜻한 오디오 코칭·거대 타이포·마일스톤 축하) — 약점(공동체 얕음·신선도 소진·의미층 없음).
**Strava 강점**(세그먼트/리더보드·kudos 피드·클럽·지도 공유) — 약점(유료화 마찰·초보 불친절·비교 스트레스 "Strava shame"·의미 없음·프라이버시).

**THE WAY의 우위(우선순위 P0):**
1. **실거리 × 실제 성경지도 = 코어 루프** — 홈이 살아있는 여정 지도, 실거리가 토큰을 전진시키고 도착 시 말씀·에피소드 해금. (둘 다 못 따라옴)
2. **중보기도 엔진 "○○를 위해 달립니다"** — 리텐션·바이럴 해자. kudos(에고) 대신 돌봄. 비러너도 유입.
3. **성구 오디오 가이드런** — NRC의 최강 기능 + 의미. 페이스 맞춘 내레이션·말씀·격려.
- P1: 글랜서블 오디오퍼스트 런 화면 · **카라반(공동 목표 협력, 느린 사람도 기여)** · 수집 유물/순례 일지 · **전례력 시즌**(대림 베들레헴·사순 광야 40일·고난주간·오순절).
- P2: 친절한 코호트 보드(속도 아닌 꾸준함) · 첫 성공 보장 온보딩 · 리플렉션 저널 · 안식일 인지 주간 리듬.
- P3: 완주자 관상적 재주행(프레스티지).
**리텐션:** 하루 1알림·항상 가까운 다음 보상·너그러운 스트릭(안식일 면제·grace day)·주간 리듬·중보 피드·전례력 재진입·다크패턴 금지.
**접근성:** 거대 고대비 단일 숫자·러닝 중 긴 텍스트 금지(오디오/햅틱)·잠금화면·야간모드·출발지 난독화.
