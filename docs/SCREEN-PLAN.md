## 1. 오늘 (Home) — "오늘 어디까지 가나"

**문제**
- `activeCourseId` 하나에 묶여 예수 여정만 보인다. 나머지 4개 여정이 홈에 존재하지 않는다.
- 히어로가 옛 회화체 히어로 아트(2MB급 원본)라 새 씬 세트와 룩이 다르다.
- 상단 배지·하단 카피가 `bg-black/25` 위 흰 글자 = 대비 미달.

**바꾸는 것**
1. 히어로를 **활성 여정의 씬 아트**로 교체. 세로 자산이므로 높이를 키우고 하단 크롭.
2. 스크림 `#201C15/85`, 히어로 안 카피는 최소화(자리 이름 + 남은 거리).
3. **여정 스트립 신설** — 5개 여정의 문장 + 진행 링을 가로로. 탭하면 여정 상세로.
   게임의 "월드 선택"이 홈에 상시 노출되는 효과. 첫 화면에 다 몰지 않되, 길은 항상 보인다.
4. 하단 CTA(순례 시작)와 중보 대상은 유지 — 이미 위계가 옳다.

**안 바꾸는 것**: Illuminated Line(라피스로 이미 교체됨), 성구 블록, 스트릭 표시.

## 2. 코스 (Courses) — "실제로 달릴 길"

**문제**
- 지금은 예수 여정의 코스 목록이다. `pilgrim-trails.json`의 **실제 순례길 6종**
  (예수 트레일 65km · 복음 트레일 62km · 카미노 프랑세스 780km · 비아 프란치제나 1900km ·
  비아 돌로로사 14처 · 성 바울 트레일 500km)이 데이터에만 있고 화면에 없다.
- 여정(성경 인물의 길)과 코스(실제 순례길)의 구분이 화면에서 드러나지 않는다.

**바꾸는 것**
1. 두 층으로 분리: **성경 여정 코스**(현행) / **실제 순례길**(신설, pilgrim-trails.json).
2. 실제 순례길 카드: 총거리 · 구간 수 · 나라 · 난이도. 지금은 "정보"로 제공하고,
   실 GPS 연동(RESUME 7번) 이후 실제 주행 모드로 승격한다. 미구현을 미구현이라 표시한다.
3. 카미노 변형(북부길·포르투갈길) 추가 — RESUME 열린 이슈.

## 3. 나 (Profile) — 별도 진행

사용자 요청으로 이번 차수에서 제외. 다음 차수에 다룬다. 예정 항목만 적어 둔다.
- 기록(누적 거리·자리·러닝)은 유지하되 **개인 랭킹·타인 비교 없음**.
- 중보 대상 관리: 이니셜 기본, 기도 제목 기본 비공개, 대상자 동의 문구.
- 설정: 단위 · 호흡 기도 on/off(기본 off) · 햅틱 · 관리자 모드.
- 스트릭은 "너그러운" 규칙(안식일 면제·grace day) — 상실 시 죄책 문구 금지.
