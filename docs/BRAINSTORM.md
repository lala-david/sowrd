# 브레인스토밍 — PROJECT THE WAY

> 2026-07-21 · 3개 렌즈(러너 경험 / 신앙 형성 / 컨셉 디자인) 병렬 브레인스토밍 종합.
> 모든 아이디어는 §4.3/§9 금지선(구원·믿음 수치화, 가챠, FOMO·스트릭 처벌, in-run 오디오 제외) 안에서 설계됨.

---

## 관통하는 테제

> **이 앱의 동사는 "증명"이 아니라 "따라감(following)".**
> 거리는 믿음을 채우는 게이지가 아니라, 이미 놓인 길 위에 잉크를 흘려 **그 길을 드러내는 것**.

마이크로카피 규칙: 어디에도 "획득/+N/달성"을 쓰지 않는다. 언제나 "길이 열립니다 / 이 자리에 닿았습니다 / 오늘 여기까지 따라왔습니다."

## A. 러너 경험 렌즈 — "달리면서 진짜 재밌게"

러너의 진짜 조건: 폰이 손에 없다(워치·주머니), 심박 160+, 한 화면 한 문장만 읽힌다, "다음 가로등까지" 심리로 버틴다, 이미 반쯤 명상 상태다. → **오디오 부재는 약점이 아니라 "진동 언어 + 호흡 리듬"이라는 남들이 못 하는 결을 연다.**

**Top 5**
1. **진동 언어 + Glance Card + "다음 사건까지 400m"** — 러너의 '다음 가로등' 생존심리를 복음서 비트로 선하게 치환. 순간 몰입의 심장.
2. **"품은 사람" 토큰 + 호흡 기도(발걸음 케이던스)** — 기도를 숙제 아닌 리듬으로. 다른 앱이 못 내는 결.
3. **여정 여권(Pilgrim Passport) + 리빌 장면 카드** — 순례자 크레덴시알식 음각 스탬프. 유치한 배지 아닌 어른스러운 소장·공유욕.
4. **"이어지는 길"(스트릭 아님) + 초대장 톤 알림 + 쉼을 축복** — 다크패턴 0으로 재방문. 신앙 앱 죄책감 마케팅의 정반대.
5. **하나의 선을 함께 채우는 공동 여정 + 격려 릴레이(속도 비노출)** — 경쟁·수치심 없이 소속감.

**진동 언어 예:** 구간 도달=짧·짧·길 / 새 장면=똑-똑 / 기도 큐=심장박동 느린 한 번 / 동행 breadcrumb=500m마다 약한 탭("나 여기 같이 있어").

**복귀 알림 규칙:** 손실 언어 금지("놓치기 전에" ❌). "길은 언제나 여기 있어요. 오늘 품고 싶은 사람이 있나요?" ✅

## B. 신앙 형성 렌즈 — "기믹 아니라 실제로 신앙에 도움"

성경적 토대: 초대교회의 첫 자칭이 **"그 도(道), the Way"**(행 9:2). "나를 따라오너라"는 문자 그대로 *걸으며* 하는 일. 엠마오 길(눅 24)에서 걸으며 말씀을 열 때 마음이 뜨거워짐 — 이 앱의 이상.

두 역설:
- **달리기에 신앙을 얹지 말고, 달리는 몸의 행위 자체를 "따라감(제자도)"의 연습으로.**
- **가장 건강한 신앙 앱은 자기를 최소화한다** — 사용자를 화면에서 하나님·사람·교회로 **돌려보낸다**(원심적 설계).

**Top 5**
1. **호흡·보폭 기도를 코어 인터랙션으로** — 들숨 "주 예수 그리스도여" / 날숨 "저를 불쌍히 여기소서". 전달이 아니라 *달리는 행위가 곧 기도*. 기믹화가 구조적으로 불가능.
2. **"복음서는 폭식하지 않는다" — 거리 + 시간(리듬) 이중 게이팅, 스트릭→안식.** 앱이 자기 최적화 논리에 저항. 쉼을 실패로 만들지 않음(개혁주의적으로 옳음).
3. **중보기도를 앱 밖으로 밀어낸다** — "한 사람 → 이번 주 실제로 문자 한 통." 채점표 없는 관계적 후속. 성육신적 설계.
4. **십자가·부활은 별도 거룩 모드** — 게임화 제거, 애통 초대, 사용자는 영웅 아닌 '증인'(구레네 시몬처럼 곁에). 부활엔 몸으로 기쁨(막달라 마리아·요한의 달음질, 요 20:4).
5. **앱은 지역 교회·이웃·식탁으로 돌려보낸다** — KPI를 스크린타임이 아니라 "몸으로 갔는가"로. 성장 지표와의 긴장을 팀이 정직하게 인정.

**협상 불가 토대:** (a) 은혜 우선 — 모든 완주 문구를 성취가 아니라 선물의 어휘로. (b) 구도자에게 정직한 환대 — 미끼도 강요도 없이. (c) 신학 검수를 콘텐츠뿐 아니라 **보상·인터랙션·카피 구조까지** 확장(기믹은 문장이 아니라 메커니즘에 숨는다).

**4대 신학 함정(이름을 알고 피하기):** 번영복음 / 공로·율법주의 / 펠라기우스적 자기구원 / 이단 인접 신비주의(사적 계시·예언 보상화). 메타 위험 = **"정량화된 영혼"**(기도·묵상마저 최적화 대상으로). → 측정하지 않는 여백을 의도적으로 남긴다.

## C. 컨셉 디자인 렌즈 — "신선하고 프리미엄하게, 제약 안에서"

### 코어 3종 (이게 제품의 전부)
1. **THE LINE — 자기를 그리는 지도.** 공생애 전체가 끊기지 않는 단 하나의 손그림 선. 걸으면 잉크가 흐르고 앞길은 고스트 라인. 핀치아웃하면 요단강→부활이 한 획. *구현: SVG path + `stroke-dashoffset`을 누적 거리에 매핑. 솔로 팀 하루 프로토타입, 룩은 최상급.*
2. **STATIONS, not Levels.** 복음서 사건 = "자리(station)". "레벨·클리어" 대신 순례 어휘. "다음 자리까지 1.2km — 첫 제자들을 부르신 곳."
3. **THE LAMP — 등불 모드(러닝 중 화면).** 시 119:105. 어두운 길 위 따뜻한 등불이 전진, 다음 장면은 어둠에 봉인(스포일 방지+안전). 근접 시 햅틱만.

### 시그니처 모먼트 — THE REVEAL
멈추면 벌어지는 1.5초: 등불 화면이 밝아지며 → 닿은 자리의 얼굴 없는 실루엣 타블로가 선으로 스스로 그려짐 → 성경 장절 한 줄 + 묵상 한 줄, 여백 80%. **톤 인지형 리워드:** 부활=빛 번짐 / 겟세마네·골고다=연출 최소, 정적. **여기에 디자인 예산 몰빵 — 사람들이 스크린샷 찍어 공유할 그 장면.**

### 예수님을 어떻게 그리나 (제약이 곧 미학)
빛으로, 또는 사람들이 일제히 향하는 방향의 실루엣으로, 또는 **앞서 걸어가는 뒷모습**("나를 따르라")으로. 얼굴 없음, 정면 클로즈업 없음, 조종 없음. 나는 언제나 *따라가는 자*. → "예수님 조종·스킬화 금지" 제약이 UX 철학 자체가 됨.

### 전례력 — "교회의 시간을 사는 인터페이스"
팔레트가 절기색을 따름(대림·사순=보라, 부활=금빛). 인위적 희소성이 아니라 *실제 절기*라 "한정"이 정당.
- **대림절:** 베들레헴 향하는 4주 여정, 촛불 4개(소망·평화·기쁨·사랑) 주마다 하나씩.
- **사순절(취향의 정점):** 앱이 스스로 미니멀해짐(인터페이스 금식). 고난주간엔 **게임 메커닉을 스스로 끔** — "이번 주간에는 거리를 세지 않습니다. 다만 그 길을 함께 걷습니다." 십자가를 보스전으로 안 만드는 가장 강력한 방법 = 그 순간 게임을 끄는 것.
- **부활절:** 가장 밝은 단 하나의 리빌(빈 무덤), 새벽 러닝과 연결.

### 시그니처 피처 Top 3 (임팩트 × 소팀 빌더빌리티)
1. **THE WAY THAT DRAWS ITSELF + The Reveal** (★★★★★ / ★★★★★) — 코어 루프이자 비주얼 아이덴티티. 이것만 있어도 데모가 된다.
2. **품은 사람 / 새겨지는 기도의 길** (★★★★★ / ★★★★★) — 기도가 지도 위 이름·빛으로 새겨져 여정이 "내가 품은 사람들의 지형"이 됨. 재방문의 감정 엔진.
3. **교회력을 사는 인터페이스**(대림 등불 + 사순 금식) (★★★★★ / ★★★☆☆) — 브랜드 정의적·언론성·신학적 정직. MVP엔 사순 금식 하나만 넣어도 강함.

**MVP 최소 조합:** 1 + 2 + THE LAMP로 "러닝 → 등불 → 리빌 → 품은 사람 새김"의 완결된 감정 루프를 먼저 증명. (현황 문서 "작게라도 돌아가는 것 먼저" 원칙과 정합.)
