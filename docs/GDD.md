# 게임 기획서 (GDD) — *동행: The Gospel Road* (가제)

> 신약 4복음서 · 예수님의 생애를 기반으로 한 **모바일 내러티브 어드벤처 RPG**
> 캐릭터를 직접 수집·성장시키며, 에피소드마다 다른 방식(퍼즐·물류·리듬·균형·추리)으로 사건을 풀어가는 게임.

- **버전:** 0.1 (기획 초안)
- **작성일:** 2026-07-20
- **레포:** `sowrd`
- **1차 목표:** 완성도 높은 기획안 확정 → 이후 디자인 목업 → MVP

---

## 0. 한 줄 컨셉 (Elevator Pitch)

> **"당신은 예수님을 따라나선 평범한 젊은이. 그분과 함께 걷는 3년의 여정에서 사람들을 만나 돕고, 동료로 맞이하고, 그들의 이야기를 모아간다."**
> — 성경 속 사건 하나하나가 서로 다른 미니게임 챌린지가 되고, 이를 깰 때마다 인물이 동료로 합류하며 능력·관계·이야기가 열린다. 따뜻하고 감동적인 스토리를 "읽는" 게 아니라 **플레이하며 겪는다.**

---

## 1. 핵심 원칙 (Design Pillars)

이 게임이 흔한 "종교 교육게임"의 실패(설교적·저퀄·지루함)를 피하는 4개의 기둥.

| 기둥 | 의미 |
|---|---|
| **① 당신은 예수님이 아니다 — 동행자다** | 플레이어는 예수님을 조작하지 않는다. 예수님은 **경외심 있게 연출되는 NPC** — 얼굴을 포함해 실제 캐릭터로 그리되(2026-07-20 사용자 결정), 따뜻하고 존중 있는 화풍으로. "조작 불가"라는 결정이 신학적·게임적 문제를 해결한다. |
| **② 교훈은 '기계장치(mechanic)'가 짊어진다** | 절대 설교로 가르치지 않는다. 나눔의 교훈은 *나눔이 보상이 되는 물류 게임*으로, 믿음 vs 의심은 *의심하면 물에 빠지는 균형 게임*으로 — 플레이어가 **직접 행동하며** 주제를 체득한다. |
| **③ 다양성 = 지루함의 적** | 매 에피소드가 다른 동사(verb): 퍼즐·물류·리듬·균형·추리. 같은 플레이가 반복되지 않는다. |
| **④ 사람을 모으는 따뜻함** | 몬스터가 아니라 **사람**을 수집한다. 열두 제자, 병이 나은 이들, 만난 사람들 — "우리 여정의 스크랩북"이 곧 진행 보상이자 감정선. |

## 2. 신학 가이드라인 (필수 준수)

**대한예수교장로회 통합측(예장통합/PCK) 정통 개혁주의 신학** 기준. 자세한 원칙은 프로젝트 메모리 `gospel-game-doctrine` 참조.

- **이단(신천지·JMS·하나님의교회·통일교 등) 교리 및 그들의 자의적 성경 재해석 일절 배제.**
- 사도신경·니케아신경·웨스트민스터 신앙고백 노선 안에서. 삼위일체·그리스도의 신성과 인성·성경적 구원론을 정통대로.
- **4정경 복음서(마태·마가·누가·요한) 본문에 충실.** 특정 교리를 주입하는 은유적 각색 금지.
- 분파적·논쟁적 해석은 피하고 **본문이 실제로 말하는 이야기와 보편적 신앙 메시지** 중심.
- **바리새인·빌라도·가야바 등 "적대자"는 만화적 악당이 아니라 동기 있는 인간으로** 묘사 (반유대주의 리스크 회피 + 전 연령 등급 유지).
- **예수님은 실제 캐릭터로 묘사한다** (2026-07-20 사용자 결정 — 기존 "빛·역광·뒷모습" 절제 연출안 폐기). 따뜻하고 존중 있는 화풍(플랫 벡터), 희화화·과도한 미형화 금지. 수난 장면의 묘사 수위는 전 연령 기준 유지. **통합측 감수 필수 대상.**
- 신학적으로 민감한 부분은 **통합측 목회자/교육자 감수** 대상으로 표시.

## 3. 핵심 재미 루프 (Core Loop)

```
   ┌─────────────────────────────────────────────────────────┐
   │                                                         │
   │   에피소드 진입 → 그 사건 고유의 챌린지 플레이           │
   │   (퍼즐/물류/리듬/균형/추리 중 하나)                     │
   │            │                                            │
   │            ▼                                            │
   │   챌린지 클리어 → ✦인물 동료로 수집✦ + 이야기 조각 획득  │
   │            │                                            │
   │            ▼                                            │
   │   동료 성장·관계 심화 (허브에서 대화/선물)               │
   │   → 고유 능력 해금 → 다음 챌린지가 더 잘 풀림            │
   │            │                                            │
   │            ▼                                            │
   │   컬렉션(사람 스크랩북) 채움 → 다음 에피소드 해금        │
   │                                                         │
   └─────────────────────────────────────────────────────────┘
```

**세 개의 톱니바퀴가 맞물린다:**
1. **수집(Collect)** — 에피소드를 깨면 인물이 동료가 된다. (도전의 보상 = 사람)
2. **성장(Grow)** — 동료마다 고유 능력. 성장·관계 심화 시 새 대사·능력 해금. → 다음 도전 공략에 실제로 도움.
3. **도전(Solve)** — 각 사건이 서로 다른 미니게임. 동료 능력을 조합해 클리어.

> **히트작 *Hades*의 관계 루프 차용:** 반복 플레이·재방문이 "노가다"가 아니라 **관계가 깊어지는 성찰**이 되도록. 동료와 다시 대화할수록 새롭고 상황에 반응하는 이야기가 조금씩 열린다("한 번 더 보고 싶은" 드립피드).

## 4. 장르 결정 & 근거

- **채택: 캐릭터 수집형 내러티브 어드벤처 RPG** (에피소드별 미니게임 + 동료 성장/관계 허브)
- **제외: 순수 비주얼 노벨** — "읽기" 중심이라 게임성 부족. (사용자 결정)
- **차용:** *Hades*식 관계 심화 허브(리텐션 엔진), *Slay the Spire*식 "재미와 학습의 분리"(교훈은 미니게임 숙련의 부산물로), 수집 게임의 "세트 완성" 도파민 — **단, 확률형 뽑기(가챠 도박)는 신앙 교육 제품에 부적절하므로 배제.** 수집은 오직 **플레이로만** 해금.

## 5. 에피소드 구조 — 4복음서를 관통하는 12장 아크

각 장 = **하나의 보편적 주제**를 **하나의 미니게임 동사**로. (설교 없이 클리어만으로 주제가 전달되게)

| # | 에피소드 | 훅 | 대표 플레이 (동사) | 주제(암묵적) | 수집 인물 |
|---|---|---|---|---|---|
| 1 | **고요한 밤** (성탄) | "별을 따라, 대상(隊商)보다 먼저." | **추리/길찾기** — 별 항법으로 베들레헴 경로, 만원인 마을에서 거처 협상 | 낮고 뜻밖의 곳에 오는 희망 | 마리아, 요셉 |
| 2 | **광야의 소리** (세례 요한) | 강가의 예언자, 몰려드는 군중과 소동 | **리듬** — 요단강 "길을 예비하라" 리듬·군중 미니게임 | 진실을 말하는 용기 | 세례 요한 |
| 3 | **광야** (시험) | 40일, 세 번의 유혹, 싸움은 없다 | **추리/대화** — 세 유혹(빵·권력·과시)을 *영리하게 거절*하며 푸는 저항 퍼즐. 절제된 연출 | 흔들리지 않는 integrity | (연출 챕터) |
| 4 | **나를 따르라** (열두 제자 부름) | 동료를 모으는 '팀 결성' 장 | **다중 미니게임 허브** — 베드로/안드레 그물 타이밍, 마태 장부 퍼즐 등으로 제자 영입. 가나 혼인 물→포도주 물류 | 소속감 — 결점 있어도 초대받음 | 베드로·안드레·마태·요한 등 |
| 5 | **산상수훈** (팔복·가르침) | 세상을 뒤집는 가르침 | **퍼즐 갤러리** — 각 가르침을 짧은 인터랙티브 비네트로 (씨 뿌리는 자=재배 시뮬 등) | "복 있다/강하다"의 재정의 | 무리 속 사람들 |
| 6 | **표적과 이적** (치유) | 소문이 퍼지고, 병자가 줄을 선다 | **물리 퍼즐 세트피스** — 지붕 뚫어 중풍병자 내리기(도르래), 폭풍 잠잠(정적의 타이밍) | 긍휼 — 소외된 이를 봄 | 병 나은 이들(카드) |
| 7 | **모두를 먹이다** (오병이어) | 떡 5·물고기 2·5천 명·한 오후 | **물류 전략** — 군중을 무리로 편성, 바구니 동선, 끝없이 불어나는 계산 | 나눔은 결핍을 이긴다 | 마태·빌립 능력 강화 |
| 8 | **내게로 오라** (물 위를 걷다) | 베드로가 배에서 내린다. 아래를 보지 마 | **균형/집중** — 빛에 시선 고정하면 물 위 유지, 의심하면 가라앉음 | 두려움보다 집중 | 베드로 관계 심화 |
| 9 | **먼 나라** (비유들) | 이야기 속 인터랙티브 단편들 | **분기 내러티브 플레이** — 탕자(돌아온 아들/원망하는 형), 선한 사마리아인(멈출까?), 잃은 양(수색) | 자비·두 번째 기회·이웃 | 등장인물별 카드 |
| 10 | **나귀 타고 오신 왕** (입성·성전) | 행진이 대치로 변한다 | **리듬 → 액션 퍼즐** — 종려주일 군중 웨이브 → 성전 상 뒤엎기(질서 회복 타임어택, 절제된 카타르시스) | 거룩한 분노·거룩한 공간 | 니고데모(전향) |
| 11 | **마지막 만찬** (다락방·겟세마네) | 마지막 식사, 이미 떠난 한 친구 | **추리/사회** — 다락방 정찰 퍼즐, 세족의 겸손 인터랙션, 겟세마네 "깨어 있으라" 지구력 챌린지, 유다 라이트 추리 | 겸손·충성·곁에 있음 | 관계 총정산 |
| 12 | **사흘째 되는 날** (수난→부활) | 가장 어두운 밤, 그리고 빈 무덤 | **절제된 "함께함"** — 수난은 이기는 챌린지가 아니라 슬퍼하는 목격자로 경험(시몬·여인들). 이후 빈 무덤 발견 퍼즐, 엠마오 도상(정체를 모르는 동행), 기쁨의 피날레 | 상실을 이기는 소망·알아봄 | 막달라 마리아 |

**(선택) 13장 — "가라"** (지상명령·승천): 에필로그이자 속편(사도행전) 훅. 모은 동료들이 흩어져 이야기를 이어간다.

> **연출 원칙:** 수난(십자가)은 *That Dragon, Cancer*의 "곁에 있음" 모델 — 승리하는 게임으로 만들지 않는다. 카타르시스(상 뒤엎기)는 성전에서만 허용, 십자가에서는 절제.

## 6. 캐릭터 로스터 — "사람을 모은다"

수집형 게임처럼: 각 인물은 **영입/친밀 가능**, **한 줄 성격**, **게임 능력**(패시브·미니게임 특기·대사 역할)을 가진다. 실루엣과 목소리가 뚜렷해 기억에 남게.

### 중심
- **예수** — *따라다니지만 조작 불가한 NPC.* 실제 캐릭터로 등장(따뜻하고 존중 있는 화풍 + 빛의 연출 병행). 게임 역할: 플레이어가 "인간의 몫"을 다한 뒤 각 사건의 '불가능한 해답'을 여는 존재.

### 열두 제자 (각자 하나의 '클래스')
베드로(충동적 열혈·물 위 챕터) · 안드레(연결자·영입 특기) · 야고보(야심·고위험 고보상) · 요한(막내 시인·성찰 로어 해금) · 마태(전직 세리·모든 자원/경제 퍼즐) · 도마(회의주의자·"검증/조사" 탐정 메커닉) · 빌립(실무 견적·물류 보조) · 바돌로매(나다나엘, 재치·설득) · 시몬(전직 열심당·긴장/은신) · 유다(회계·비극적 내부자·라이트 사회추리) · 다대오 & 알패오의 야고보(무명의 두 사람·"숨은 영웅" 수집 스레드).

### 가족 & 선구자
마리아(어머니·감정의 앵커·1·12장 북엔드) · 요셉(성실한 보호자·성탄 튜토리얼 가이드) · 세례 요한(광야의 예언자·게스트 대형 인물) · 막달라 마리아(부활 첫 증인·12장 피날레 시점).

### 만난 사람들 ("인카운터" 수집 카드)
삭개오(나무 위 세리·등반 미니게임+나눔 보상) · 바디매오(외치는 맹인·소리 기반 지구력) · 사마리아 여인(우물가 대화 펜싱) · 나사로와 마르다·마리아(친구들·후반 감정 스테이크) · 나은 병자들(도운 사람 카드 갤러리 = 여정의 따뜻한 스크랩북).

### 권세자 & 적대자 (만화가 아니라 '사람'으로)
니고데모(밤에 찾아온 호의적 바리새인·영입 가능한 "전향") · 가야바(제도를 지키려는 대제사장·로마 보복에 대한 실제 두려움이 동기) · 바리새인들(개인으로·규례를 지키려는 신념·"함정 질문" 리들 미니게임) · 빌라도(손 씻는 실용주의 관리·도덕적 비겁의 연구) · 백부장(점령이라는 배경·"큰 믿음"의 인간화).

## 7. 미니게임 타입 카탈로그 (동사별)

같은 장르 반복을 막는 게 핵심. **퍼즐 · 물류 · 리듬 · 균형 · 추리** 5대 동사 + 파생.

- **퍼즐** — 씨 뿌리는 자(재배 시뮬), 달란트(투자/리스크), 지붕 뚫기(도르래 물리), 산상수훈 비네트.
- **물류/전략** — 오병이어(군중 편성·바구니 동선), 가나 혼인(호스트 물류), 성탄 거처 협상.
- **리듬** — 요단강 "길을 예비하라", 종려주일 군중 웨이브.
- **균형/집중** — 물 위 걷기(시선 고정), 폭풍 잠잠(정적 달성), 겟세마네 "깨어 있으라".
- **추리/사회** — 광야의 세 유혹(거절 대화 듀얼), 엠마오 도상(정체를 밝히는 미스터리), 다락방 정찰, 유다 라이트 사회추리, 사마리아 여인 대화.
- **분기 내러티브 플레이** — 탕자·선한 사마리아인·잃은 양 등 비유를 *플레이*.
- **월드/이동 레이어(선택)** — 가버나움·예루살렘·갈릴리 해변을 허브로 자유 이동, 지역 주민 돕는 사이드 퀘스트 + 인카운터 카드 수집.

## 8. 진행 · 보상 시스템

- **컬렉션(사람 스크랩북):** 영입한 동료·나은 사람·만난 이들을 카드로 모은다. 세트 완성 도파민. 각 카드에 성경 구절 출처·한 줄 이야기.
- **동료 능력 & 성장:** 각 동료는 미니게임에서 쓰는 고유 패시브/액티브. 관계 심화 시 능력·대사 해금.
- **관계 심화(허브):** 여정의 "쉼터"(길·집·배)에서 동료와 대화·선물. 재방문할수록 상황 반응형 새 대사(*Hades* 드립피드).
- **보상 리듬:** 30~90초마다 마이크로 피드백(대사 해금·카드 획득), 10~15분마다 의미 있는 마일스톤(에피소드 클리어). 노력 대비 보상 3:1.
- **난이도:** 낮은 바닥/높은 천장 — 누구나 클리어 가능하되, 우아한/고득점/'통찰' 해법으로 숙련자도 만족. **공개 순위표로 수치 비교·수치심 유발 금지.**
- **데일리 훅:** *초대형(invitational)* — 오늘의 묵상/보너스. 안 해도 벌칙 없음(FOMO·강제성 배제).
- **수익모델 스탠스:** 확률형 뽑기·페이투윈 없음. (원한다면 완전판 구매/후원/교회·학교 라이선스 모델을 후속 검토.)

## 9. 톤 & 아트 디렉션

- **톤:** 따뜻하고 감동적. 유머 허용(제자들의 티격태격, 열혈 베드로) + 경외(이적의 스펙터클). 경건함은 *예수님과 수난을 다루는 방식*에서 지키고, 그 외에서는 재미를 빼지 않는다.
- **아트 스타일 후보(솔로/AI 제작으로도 프리미엄하게 보이는 것):** **플랫 벡터 일러스트** 또는 **페이퍼컷(레이어)** 또는 **일관된 페인터리**. 실사·풀 픽셀아트는 지양(일관성·언캐니 리스크).
- **일관성 전략:** 캐릭터 = 중립 베이스 포즈 + 표정 레이어(눈·입) 교체 → 한 번 생성으로 여러 감정. 배경 = 패럴럭스 레이어. UI = SVG 벡터(전 화면 선명). 팔레트를 hex로 고정.
- **경외의 신호 = 고증:** 1세기 이스라엘의 실제 배경 고증을 아트로. (연구가 보이면 그것이 곧 존중.)

## 10. 기술 스택 (모바일 우선)

> 핵심 원칙: 이 게임은 "90% UI·대사·상태"다. Unity처럼 만들지 말고 **리치한 React 앱**처럼 만든다.

**권장 스택:**
- **Vite + React 19 + TypeScript** (베이스)
- **Motion** (구 Framer Motion, `motion/react`) — 화면 전환·마이크로 인터랙션
- **inkjs** — 분기 대사/스토리 엔진. 작가는 `.ink` 파일 작성 → JSON 컴파일. 세이브도 네이티브 직렬화.
- **Zustand (+ persist)** — 게임 상태·세이브 시스템
- **Zod** — 콘텐츠(JSON) 스키마 검증
- **idb-keyval (IndexedDB)** — 세이브 저장
- **Howler.js** — 오디오(BGM/SFX)
- **@pixi/react + pixi.js** — *선택.* 파티클·이적 이펙트 등 캔버스 연출이 필요한 순간에만 React 안에 얹기. (Phaser는 이 게임엔 과함.)
- **vite-plugin-pwa** → **Capacitor** — 웹 PWA로 먼저 배포(설치형·오프라인), 이후 같은 빌드를 앱스토어용으로 래핑.

**콘텐츠 = 데이터 (기획자가 코드 없이 추가):**
- 대사/분기 → `.ink` 파일 (JSON 컴파일)
- 구조 메타데이터(에피소드/캐릭터) → JSON + Zod 검증
- 엔진(거의 안 바뀜)과 콘텐츠(계속 바뀜) 분리. 새 에피소드 = `epXX.ink` + `epXX.json` + 아트 드롭인, 엔진 수정 0.
- 세이브 = `{ inkState, gameState(zustand), version }`, IndexedDB 저장 + 수동 내보내기/가져오기.

## 11. MVP 범위 (검증 우선)

**목표: 톤·재미 루프를 검증할 "플레이 가능한 1~2 에피소드".**

- **에피소드 후보:** 8장 "물 위를 걷다"(균형/집중 — 가장 상징적이고 감정적) + 4장 일부(제자 영입 = 수집 루프 시연). 또는 6장 지붕 퍼즐.
- **렌더링:** React DOM + CSS + Motion만. (Pixi·GSAP·Phaser 없음)
- **대사:** inkjs 처음부터.
- **상태/세이브:** Zustand + persist → localStorage(후에 IndexedDB).
- **오디오:** Howler 2채널(BGM+SFX).
- **배포:** Vite build + vite-plugin-pwa → Netlify/Vercel/Cloudflare. 즉시 설치형·오프라인. (Capacitor·앱스토어는 이후.)
- **콘텐츠:** 에피소드 1개 JSON + `.ink` + Zod 스키마. 데이터 구조를 초반에 확정(나중에 바꾸면 비쌈).
- **검증 지표:** "이 루프가 재밌는가? 감동이 오는가? 설교처럼 느껴지지 않는가?"
