# 자리 시네마틱 101편 — 실행 계획 (2026-08-21 초안)

> 상태: **계획 — 착수 전 창업자 결정 4건 필요(§8)**. 대적 5편(완료)의 파이프라인을
> 자리 101곳 전체로 확장한다: 자리마다 ~13초 · 4~5컷 · 1080²(또는 720²) 시네마틱.

## 0. 한 줄

대적 영상의 문법(키프레임 생성 → 켄번즈 → 컷 전환 → 무드 이펙트 → 자막)을
**여정의 모든 자리**에 적용한다. 단, 자리는 대결이 아니라 **사건**이므로
서사 구조가 다르다: 승리가 아니라 **도착과 묵상**이다.

## 1. 규모와 비용 (정확한 산수)

| 항목 | 수량 |
|---|---|
| 자리 | 예수 33 + 아브라함 10 + 출애굽 16 + 바울 28 + 베드로 14 = **101** |
| 컷/자리 | 5컷 (기존 자리 그림 1 + **신규 생성 4**) |
| 신규 생성 | 101 × 4 = **404장** (+재생성 여유 15% ≈ 총 ~465장) |
| 크레딧 | 465 × 2 = **~930 / 3,575** (26%) — `RECRAFT_KEY` 필수(MCP 잔여 14로 불가) |
| 생성 시간 | 장당 ~20초 직렬 → **~2.6시간** (배치 스크립트, 실패 자동 재시도 목록) |
| 렌더 시간 | 편당 ~10초 → **~20분** |
| 최종 용량 | 1080²·CRF21 ≈ 4MB/편 → **404MB** / 720²·CRF23 ≈ 1.6MB → **~160MB** |

## 2. 컷 문법 — "도착의 5컷" (대적의 승리 서사와 다르다)

1. **접근** — 그 지역의 원경, 길이 화면 안으로 이어짐 (여정의 감각)
2. **도착** — 장소가 눈앞에 (기존 episode-art SUBJECTS의 원경 변주)
3. **사건** — 기존 자리 그림(이미 101장 있음 — 사건의 사물이 말한다)
4. **말씀** — 사물 클로즈업 + `verseKrShort` 자막 (이 자리의 보상은 말씀)
5. **머묾** — 같은 장소의 빛이 바뀐 컷(황혼/새벽) + 여운 페이드

## 3. 무드 프리셋 — 신학 가드를 이펙트에 (기계 강제)

`moods.ts`가 프리셋을 **자동 선택**한다. 수작업 예외 없음:

| mood | 이펙트 | 금지 |
|---|---|---|
| joy·wonder | 빛내림(godray) + 표준 전환 | — |
| everyday·compassion | 그레인·비네트만, fade 전환 | 빛내림 억제 |
| wilderness | 아지랑이/먼지 오버레이 | 빛내림 금지 |
| **lament** | **구름 그림자·느린 fade만. 빛내림·fadewhite·vertopen 금지, 자막도 "지났습니다" 톤** | 축하 일체 |

십자가(golgotha·finished)·수난 주간: **컷 문법 자체를 단순 2~3컷 + 침묵**으로 별도 처리.
십자가=보스전 금지의 영상판 — 검사 스크립트가 lament 자리에 금지 이펙트가 붙으면 빌드를 깨뜨린다.

## 4. 프롬프트 파이프라인 (404장을 사람이 다 쓸 수 없다)

1. **씨앗**: `episode-art.mjs`의 SUBJECTS 101줄(사건 사물 묘사)이 이미 있다 — 컷3의 정본.
2. **파생 규칙**: 컷1·2·4·5는 씨앗의 규칙 변주 — "distant view of {subject}", "the road approaching {place}",
   "close detail of {핵심 사물}", "{subject} at dusk". 서브에이전트가 101×4 초안 생성.
3. **수작업 오버라이드**: 자리 ~20곳(수난·기적·환상 등 민감/중요)은 손으로 다시 쓴다.
4. **기계 검수**: 금지어(후광·예수 묘사·십자가 장식·인물), lament 톤, 스캐폴드 준수 —
   `scripts/check-video-scenes.mjs` 신설.
5. **표본 검수**: 배치마다 `contact-sheet.mjs`(기존 도구)로 컨택트시트 → 눈 검수 → 불합격 재생성 목록.

## 5. 렌더 파이프라인

`adversary-video.mjs`를 일반화한 `scripts/episode-video.mjs`:
- 매니페스트 자동 생성: 자리 데이터(id·place·verseKrShort·mood) + 컷 규칙 → CLIPS 101개
- 여정별 시그니처 전환(단조로움 방지): 예수=갈릴리 빛(fade+godray) · 출애굽=사막 먼지 ·
  바울=항해 비/파도 · 아브라함=별밤 · 베드로=성벽 그림자
- 자막: 컷1 지명(큰 세리프) · 컷4 말씀(중앙) · 컷5 없음(여운)
- 출력: `showcase/episodes/{journey}/{id}.mp4`

## 6. 배포·노출 전략 (결정 필요 — §8-③)

| 옵션 | 내용 | 트레이드오프 |
|---|---|---|
| A. 전시실 갤러리 | `/showcase.html`에 여정별 탭 추가, 포스터+탭 재생 | 앱 IA 불변(대원칙 안전). 용량 전부 gh-pages |
| B. 앱 자리 상세 | EpisodeDetail에 "이 자리의 길" 영상(도달 무관 — 본문처럼 항상 열림) | 제품 통합 최고. 단 화면 추가 요소 — 대원칙 검토 필요 |
| C. 리빌 연출 대체 | 도달 순간 해당 영상 재생 | **비추천** — 기존 인장·걷힘 연출과 충돌, 4MB 로딩이 순간을 죽임 |

용량: **720² CRF23(~160MB) 권장** — gh-pages 리포가 400MB 되는 것은 피한다.
장기적으로 리포가 무거워지면 Cloudflare R2(무료 10GB) 이관 — 프라이버시 무관(정적 파일).

## 8. 착수 전 결정 4건

1. **RECRAFT_KEY** — 절대 게이트. 없으면 시작 못 한다 (930크레딧/3,575).
2. **해상도**: 1080²(404MB) vs **720²(160MB, 권장)** — 폰 화면에선 차이 미미.
3. **노출 위치**: §6의 A(전시실 갤러리, 권장 시작점) / B(앱 자리 상세) / A+B.
4. **수난 자리 범위**: golgotha·finished 등 십자가 자리를 영상에서 **아예 제외**할 것인가,
   §3의 침묵 문법으로 만들 것인가 — 신학 검수 없이 내가 정하지 않는다.
